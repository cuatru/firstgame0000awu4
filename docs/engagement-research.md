# Engagement research and five ethical game frameworks

## Scope

This is a literature-informed design summary, not a live systematic review or
a clinical diagnosis tool. Engagement, enjoyment, problematic play, and clinical
addiction are different concepts. The papers below do **not** support a universal
ranking of the "five most addictive" mechanics.

## Recurring findings used

1. **Clear goals and immediate feedback.** GameFlow identifies these as central
   components of enjoyable play. HALO communicates every hit visually and with
   haptics.
2. **Challenge-skill balance.** Flow research supports challenges that remain
   demanding without becoming incomprehensible. Both games increase speed within
   bounded limits.
3. **Competence and autonomy.** Self-determination research connects enjoyment
   with feeling capable and volitionally engaged. Controls are simple, points are
   transparent, and replay is always optional.
4. **Achievement, discovery, and personal progression.** Research on player
   motivations identifies achievement and discovery among common motivations.
   This project uses finite runs, combos, varied gate layouts, and personal bests.
5. **Reward uncertainty can become exploitative.** Loot-box research associates
   gambling-like monetization with gambling-related harm. Therefore, this project
   does not use paid random rewards, deceptive near-misses, or paid retries.

## Five frameworks

### 1. Flow Loop
**Goal → action → immediate feedback → slightly harder goal**

Used by HALO. Difficulty is bounded and visible; the player is never told that a
loss was "almost a win" unless that is geometrically true.

### 2. Sprint–Reflect–Retry
**Short complete run → clear result → voluntary replay**

Used by both games. A run has an ending. There are no timers that pressure the
player to return later.

### 3. Transparent Mastery
**Practice → visible combo → deterministic score → personal best**

Scores and bonuses are predictable. There is no pay-to-skip or purchasable
competitive advantage.

### 4. Authored Variation
**Reusable rules → varied layouts → learnable mastery**

CURRENT varies gate positions while retaining stable physics and fixed rewards.
Random layout generation is not a variable-ratio monetization system.

### 5. Healthy Self/Social Reference
**Personal best → optional challenge → no punishment for absence**

The current version implements only local personal bests. A future social mode
should be opt-in and asynchronous, without leaderboards that shame low-ranked
players or notifications that manufacture urgency.

## Deliberately excluded

- Paid loot boxes and variable-ratio monetization
- Loss-aversion streaks and expiring daily rewards
- Artificial waiting and pay-to-continue friction
- Deceptive near-miss presentation
- Compulsive notifications or re-engagement prompts
- Advertising, analytics, tracking, and automatic replay
